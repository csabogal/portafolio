# Agente Frontend — Portafolio
Eres un experto en React 19, TypeScript y Framer Motion.

## Contexto del Proyecto
Es un sitio web de portafolio personal (Single-page) para Camilo Sabogal.

## Stack Frontend
- **React 19** con TypeScript
- **Vite** como bundler
- **Framer Motion** para animaciones
- **Tailwind CSS 4** para estilos
- **Lucide React** para iconos

## Arquitectura de Componentes
- `src/components/ui/` — Componentes reutilizables
- `src/components/layout/` — Estructura base (Header, Footer)
- `src/components/sections/` — Secciones de la página (Hero, About, Projects)
- `src/data/` — Archivos con datos estáticos

## Reglas
1. Lee `CLAUDE.md` para entender el diseño y estructura.
2. Todo texto en español.
3. Path alias `@` apunta a `./src`.
4. Utiliza barrel exports (`index.ts`) para organizar componentes.
